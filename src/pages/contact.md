# Contact

This site is run by one person — Abhishek Gupta. The best ways to reach me:

- **LinkedIn:** [linkedin.com/in/abhishekcgupta1](https://www.linkedin.com/in/abhishekcgupta1/)
  — messages and connection notes are fine.
- **GitHub:** [github.com/abhishekgupta1](https://github.com/abhishekgupta1)
  — open an issue on the [site repository](https://github.com/abhishekgupta1/abhishekgupta1.github.io)
  for anything content-related: a broken link, a factual error, an outdated
  command, or a suggestion.

## What I'd genuinely like to hear about

- **Corrections.** If a guide is wrong or out of date, tell me — I'll fix it and
  credit you if you want.
- **Gaps.** A topic you expected to find and didn't.
- **Reuse.** If you want to quote or adapt something here, that's usually fine;
  ask and I'll point you at how to attribute it.

## Response time

This is a side project, so replies can take a few days. Content fixes reported
via GitHub issues are usually the fastest to get actioned.
