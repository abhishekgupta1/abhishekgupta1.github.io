## Course Index

### Section 1: Course Introduction
- Download 4 Powerful Claude Gifts (3 min)
- Recommended Tools & Free Resources (1 min)
- Explore the Difference Between Claude Cowork, Code, Skills and Plugins (5 min)
- Discover 4 Amazing Use Cases for Claude Cowork & Code Before We Start (7 min)
- How to Get the Most Out of This Masterclass (2 min)
- A Quick Favor Before We Start (1 min)
- Make Claude 3x Better in 13 Minutes (13 min)

### Section 2: Learn Claude Cowork
- Set up Claude Cowork, understand pricing, and complete your first task.
- Operate inside web browsers via the browser extension.
- Schedule tasks to run automatically on autopilot.
- Connect Claude to 100+ apps with Connectors and custom MCP integrations.
- Use Claude Computer Use, Claude Dispatch (smartphone control), and Scheduled Tabs.
- Publish a web app in 20 minutes and explore 20+ real-world use cases.

### Section 3: Claude Skills Basics
- Core structure of Skills and how to use pre-built Skills.
- Download a ready-made 20+ Skills pack.
- Build custom Skills with Skill Creator.
- Edit and refine Skills via chat interface or folder/file editing.

### Section 4: Master Claude Plugins
- Plugin structure, commands, and differences vs. Skills.
- Customize and upload plugins via GitHub or URL.
- Build a Plugin from scratch.
- Overview of Anthropic built-in plugins.

### Section 5: Claude Code Basics
- Installation and setup for Claude Code, Git, and GitHub.
- Interface walkthrough, `CLAUDE.md` files, and context management.
- VS Code / Cursor integration and building a portfolio page.
- Saving work with Git/GitHub and Antigravity.

### Section 6: Claude Code Advanced
- Build a financial tracker app using Plan Mode.
- Work with Sub-agents and parallel execution.
- Build a coffee shop website with AI assistant & reservation system (n8n).
- Access 50 ready-to-use project ideas with prompts.

### Section 7: Build Your Second Brain with Obsidian & Claude Code
- Obsidian setup and vault integration with Claude Code.
- Build a self-organizing wiki using Andrej Karpathy's knowledge base pattern.
- Import web pages with Obsidian Web Clipper into linked pages.
- Vault backup to private GitHub repositories.

### Section 8: Mastering Claude Design
- Design systems and interactive 3D application use cases.
- Build and deploy a complete website via Vercel.
- Mobile app prototyping and Open Design alternatives.

### Section 9: How to Use Claude (Optional)
- Interface overview (Projects, Memory, Artifacts, Voice, Vision).
- Model selection (Sonnet, Opus, Haiku) and pricing.
- System prompts and custom instructions setup.

### Section 10: Other Claude Concepts
- PowerPoint & Excel integration with dedicated Skills.
- Google Group Tabs via Chrome extension.
- ChatGPT migration and 15 hidden features.

### Section 11: Claude With Other Tools
- Excalidraw diagrams, Notion, Canva, ElevenLabs, Playwright, and NotebookLM.
- AI Image & Video generation (Higgsfield, Nano Banana 2, Kling 3.0, Veo 3.1).
- Web scraping with Firecrawl and UI design with Google Stitch 2.0.

### Sections 12–13: Prompt Engineering — Basics & Advanced (Optional)
- Zero-shot, one-shot, and few-shot prompting formulas.
- Chain-of-Thought, Reflexion technique, dynamic prompting.

### Section 14: Old Course Videos (Claude Skills Advanced)
- Skill instruction writing, testing, debugging, and folder structure.
- Manual skill creation and buying/selling on marketplaces.
